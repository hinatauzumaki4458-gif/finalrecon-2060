```

                        [--ultimate-9030] [--ultimate-2060] [--auto-pilot]

                        [--scan-ports] [-w WORDLIST] [--rockyou]
```

| Option | Description |

| Option | Description |

| `--feature-2060-all` | ALL 2060 modules |
| `--scan-ports` | Scan ports 80/443 |
| `-w, --wordlist` | Wordlist path |
| `--rockyou` | Use rockyou wordlist |
